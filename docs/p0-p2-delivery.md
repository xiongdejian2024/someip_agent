# P0–P2 功能交付与验收记录

本轮目标：完成 2026-10-03 调研列出的六项 P0–P2 功能，每个小功能验证后单独提交并推送。
同时先修复调研发现的网页 64 位整数精度和监控应用层丢弃计数。开发提交使用 `[skip ci]`；
全部开发结束后统一执行原生、安装包与前端验收，不把单元测试当作线上互操作证明。

车型源冲突、Bootes、Windows、新增 IPv6 保持延期；不自动追加远程认证、TP/E2E、HIL、
企业鉴定或固定 8/24/72 小时测试。新增功能复用现有原生协议栈、权限门禁与审计。

## 完整验收清单

- [ ] 整数正确性：参数输入、HTTP、WebSocket、SSE、详情和导出无损保留 int64/uint64；
  不将精确大整数默默转换为波形浮点数，正常协议 ID 仍为 number。
- [ ] 监控计数：独立报告抓包丢包、订阅队列丢弃、历史缓冲淘汰和前端缓冲淘汰；
  满载、清空、重连与多个订阅者测试，零值与未知值不混淆。
- [ ] P0 真实服务周期激励：复用激活 ARXML 的完整事件 schema、部署、字节序和 EventGroup；
  多信号合成一个事件，UDP/TCP/内部通道及停止清理有实际证据，不猜测缺失布局。
- [ ] P1 工程管理：保存/打开/重启恢复工作集、激励、服务与监听配置、波形选择；
  版本化导入导出、迁移、备份与恢复，拒绝密钥和任意本地路径，恢复不自动发包。
- [ ] P1 自动场景：前置条件、调用/通知、等待、确定性断言、清理、参数化；
  产品 CLI/API 无界面运行，失败/取消可靠清理，JUnit/HTML 和原始证据关联。
- [ ] P1 记录回放：持续录制、文件轮转、有界资源、记录导出、时间轴联动；
  离线回放含过滤、暂停/单步/时间倍率，不自动重放到真实网络。
- [ ] P2 激励与同步：开放随机/序列，补 CSV、阶跃、每任务随机种子与状态机；
  多信号统一时间基准、同步启动、暂停/恢复/单步和时间倍率，不把冻结界面当暂停。
- [ ] P2 结果比较：持久测试历史、基线比较、版本/ARXML/配置/种子/断言/报文完整证据包；
  审计与请求关联、导出无密钥、证据变更可检测。
- [ ] 整体验收：完整测试、构建、原生虚拟网络及独立安装运行，文档与支持边界一致；
  所有功能提交已推送，用户既有 IPv6 草稿不改动。

## 开发日志

### 2026-10-03：开始实施

当前基线 `2a3554e`，产品版本 0.1.2；本地与 origin/main 同步。
现有前端没有无损 JSON 工具；Pi 子工程的 json-bigint 不在前端依赖图中。
选择 MIT 的 lossless-json 4.3.1，复用其解析/序列化，不自写 JSON 解析器或修改全局 BigInt 原型。

### 小块 1：业务整数无损传输

网页参数、HTTP 响应、监控 WebSocket、智能体 SSE、原生响应详情与 JSON 导出统一保留大整数。
安全范围内的数字保持 number；大整数使用 bigint，发送仍为 JSON 数字。指数/小数形式的不安全
整数明确拒绝，溢出/下溢明确失败；波形只接收有限 number/boolean，不将 bigint 静默转为 float。
新增 `node scripts/check_json_precision.mjs` 验证 int64/uint64、嵌套值、HTTP 往返与 SSE。
前端 typecheck/build、既有 agent_stream 和 monitor_buffer 回归通过；整轮原生/安装包验收仍待完成。

### 小块 2：监控分层丢弃与淘汰计数

后端分别统计发布、历史淘汰、手动清空、订阅队列丢弃；每个订阅者独立计数，退订释放登记，
重连从新的连接计数开始，但保留本进程累计。后端 UUID 标识计数周期，重启不混合旧周期。
REST summary 与实际 WebSocket snapshot/message/heartbeat 携带相同统计契约。
前端继续 100 ms 批量刷新，独立显示本页面 Trace/采样淘汰与后端计数；明确与 libpcap
内核/接口丢包区分，未知不显示为零，手动清空不伪装成网络丢包。
新增 3 项后端测试覆盖多订阅者、满载、清空、重连、非法容量和真实 TestClient WebSocket；
前端 20,000 帧缓存回归、分层指标 SSR、typecheck/build 通过。SSR 不等同于真实浏览器验收。

### 小块 3：完整事件原生周期通知入口

复用已有 vsomeip/Boost.Asio 周期任务，通过服务 API、服务页与智能体控制台配置完整事件参数，
不增加 Python 逐周期发包线程。冻结的 ARXML catalog 决定 schema、字节序、部署与 EventGroup。
启动、更新、停止均写审计；查询返回实际原生调度计数，明确不作为线上交付证明。
每个 server 成员当前最多一个固定参数周期任务；不同事件使用独立成员，动态多信号仍待后续小块。
非法完整参数更新被原生 codec 拒绝，旧任务继续；毫秒转换使用 Decimal，29 ms 不误变为 30 ms。
网页保留无损整数输入；控制台周期写操作继续受显式 mutation 门禁约束。

隔离容器中真实原生周期、兼容性与时序测试共 50 项通过、零跳过；完整结构体/数组事件、
EventGroup=7 的冻结配置和黄金 payload 均有接收证据。另一个会话/周期/监控组合 20 项通过。
前端 typecheck/build 与整数往返回归通过。新入口 UDP/TCP 线上验收、动态激励与完整 P0 尚未完成。

### 小块 4：版本化工程存储与安全恢复 API

复用 SQLite/Pydantic，不新增依赖。工程格式 v2 保存模型投影、服务、周期、监听、标量激励与
工作集/波形选择；v1 自动迁移为 v2。文件仅包含配置，不包含运行 PID、socket、密钥、
本机二进制路径或发送授权；导入不恢复授权，也不启动任何服务/监听/激励。
SQLite 事务支持乐观 revision 检查与并发保存；每工程保留最近 20 份旧版本，恢复生成新版本，
不覆盖旧历史。工程最多 100 个，单文档 8 MiB，上下限与非法 ID 均有明确拒绝。
当前工程选择持久化；重启恢复模型与草案但保持运行为空。打开工程时需先停止并释放活动会话。
新 API 覆盖创建/保存/打开/当前/导入/导出/备份/恢复，操作写审计、异常保留完整堆栈。
9 项针对性测试通过，包括实际 HTTP 往返、重启不运行、导出无密钥、迁移、并发冲突与备份轮转。
网页采集与恢复尚待下一个小块，不把后端存储完成宣称为整个工程管理交付。

### 小块 5：网页工程工作集与配置恢复

网页增加工程管理栏，可保存、另存、打开、导入/导出、检查历史备份、恢复旧配置为新修订。
复用现有无损 JSON，完整事件的整数参数不损失；增加只校验配置的 API，不将草案当执行脚本。
服务草案可在未启动时加入，保存的多成员配置由明确按钮手动初始化；工作信号/参数、监听草案、
ARXML 服务选择和示波器勾选进入工程草案。切换工程重新初始化页面草案，不复用旧页面运行选择。
静态 SSR、typecheck/build、JSON 与监控计数回归通过；隔离容器工程+周期测试 22 项通过、零跳过，
实际原生活动会话阻止切换，停止后打开带周期参数的工程不自动发送。
ego-browser 在隔离实例实际点击保存/打开/ARXML 导入/服务草案/仿真勾选并重载：修订 3、
工作信号和初始值 37.5 均恢复，实际服务与仿真 API 均为空数组。未使用宿主数据或启用在线发送。

### 小块 6：连续记录、完整性校验与只读时间轴回放

复用 stdlib JSONL/zipfile/hashlib 和既有 MonitorBuffer，记录独立分段，不依赖网页或后端旧缓冲。
队列、单帧、分段、每记录/总磁盘额度与记录数量均有上限；额度停止、丢弃与中断不冒充完整。
监控发布时标记 monotonic 到达时间；原子 detach 保留退订的最终丢弃计数，正常停止排空队列。
封存分段 fsync + SHA-256，读取/导出重新校验；拒绝宿主路径和符号链接。ZIP 下载临时文件受
两路并发限制并在完成/取消后清理。回放没有网络发送入口，也不注入实时监控缓存。
网页开放录制、停止、ZIP 导出、时间轴、过滤、暂停/单步/倍率及波形联动；每页与释放批次有界。
确定性前端测试覆盖暂停、单步、倍率、分页等待、跳转和顺序校验，前端构建及旧缓冲回归通过。

隔离容器实际录制原生 provider/consumer 的黄金 payload，清空历史缓冲后仍可回读；记录/监控/
工程/周期组合 30 项通过、零跳过。内部 Trace 方向统一标为 sim，接收证据由 Consumer_client
成员元数据确认，不伪装成线上 rx。首次用例错误预期清空 200（实际 204），已按现有接口修正；
第二次误用内部方向 rx 的断言也已修正为实际成员接收，未改生产语义。
ego-browser 实际记录 1,057 帧、队列丢弃 0；单步、2× 播放、暂停、Service ID 过滤和 5,010 ms
跳转通过，波形显示 37.5。真实浏览器下载 ZIP 后重新验全分段 SHA-256 与清单帧数通过。
