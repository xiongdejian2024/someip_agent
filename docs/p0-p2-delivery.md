# P0–P2 功能交付与验收记录

本轮目标：完成 2026-10-03 调研列出的六项 P0–P2 功能，每个小功能验证后单独提交并推送。
同时先修复调研发现的网页 64 位整数精度和监控应用层丢弃计数。开发提交使用 `[skip ci]`；
全部开发结束后统一执行原生、安装包与前端验收，不把单元测试当作线上互操作证明。

车型源冲突、Bootes、Windows、新增 IPv6 保持延期；不自动追加远程认证、TP/E2E、HIL、
企业鉴定或固定 8/24/72 小时测试。新增功能复用现有原生协议栈、权限门禁与审计。

## 完整验收清单

- [ ] 整数正确性：参数输入、HTTP、WebSocket、SSE、详情和导出无损保留 int64/uint64；
  不将精确大整数默默转换为波形浮点数，正常协议 ID 仍为 number。
- [ ] 监控计数：独立报告抓包丢包、订阅队列丢弃、历史缓冲淘汰和前端缓冲淘汰；
  满载、清空、重连与多个订阅者测试，零值与未知值不混淆。
- [ ] P0 真实服务周期激励：复用激活 ARXML 的完整事件 schema、部署、字节序和 EventGroup；
  多信号合成一个事件，UDP/TCP/内部通道及停止清理有实际证据，不猜测缺失布局。
- [ ] P1 工程管理：保存/打开/重启恢复工作集、激励、服务与监听配置、波形选择；
  版本化导入导出、迁移、备份与恢复，拒绝密钥和任意本地路径，恢复不自动发包。
- [ ] P1 自动场景：前置条件、调用/通知、等待、确定性断言、清理、参数化；
  产品 CLI/API 无界面运行，失败/取消可靠清理，JUnit/HTML 和原始证据关联。
- [ ] P1 记录回放：持续录制、文件轮转、有界资源、记录导出、时间轴联动；
  离线回放含过滤、暂停/单步/时间倍率，不自动重放到真实网络。
- [ ] P2 激励与同步：开放随机/序列，补 CSV、阶跃、每任务随机种子与状态机；
  多信号统一时间基准、同步启动、暂停/恢复/单步和时间倍率，不把冻结界面当暂停。
- [ ] P2 结果比较：持久测试历史、基线比较、版本/ARXML/配置/种子/断言/报文完整证据包；
  审计与请求关联、导出无密钥、证据变更可检测。
- [ ] 整体验收：完整测试、构建、原生虚拟网络及独立安装运行，文档与支持边界一致；
  所有功能提交已推送，用户既有 IPv6 草稿不改动。

## 开发日志

### 2026-10-03：开始实施

当前基线 `2a3554e`，产品版本 0.1.2；本地与 origin/main 同步。
现有前端没有无损 JSON 工具；Pi 子工程的 json-bigint 不在前端依赖图中。
选择 MIT 的 lossless-json 4.3.1，复用其解析/序列化，不自写 JSON 解析器或修改全局 BigInt 原型。

### 小块 1：业务整数无损传输

网页参数、HTTP 响应、监控 WebSocket、智能体 SSE、原生响应详情与 JSON 导出统一保留大整数。
安全范围内的数字保持 number；大整数使用 bigint，发送仍为 JSON 数字。指数/小数形式的不安全
整数明确拒绝，溢出/下溢明确失败；波形只接收有限 number/boolean，不将 bigint 静默转为 float。
新增 `node scripts/check_json_precision.mjs` 验证 int64/uint64、嵌套值、HTTP 往返与 SSE。
前端 typecheck/build、既有 agent_stream 和 monitor_buffer 回归通过；整轮原生/安装包验收仍待完成。

### 小块 2：监控分层丢弃与淘汰计数

后端分别统计发布、历史淘汰、手动清空、订阅队列丢弃；每个订阅者独立计数，退订释放登记，
重连从新的连接计数开始，但保留本进程累计。后端 UUID 标识计数周期，重启不混合旧周期。
REST summary 与实际 WebSocket snapshot/message/heartbeat 携带相同统计契约。
前端继续 100 ms 批量刷新，独立显示本页面 Trace/采样淘汰与后端计数；明确与 libpcap
内核/接口丢包区分，未知不显示为零，手动清空不伪装成网络丢包。
新增 3 项后端测试覆盖多订阅者、满载、清空、重连、非法容量和真实 TestClient WebSocket；
前端 20,000 帧缓存回归、分层指标 SSR、typecheck/build 通过。SSR 不等同于真实浏览器验收。
