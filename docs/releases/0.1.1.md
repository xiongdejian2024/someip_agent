# SOME/IP Agent 0.1.1

首个正式签名的 Linux x86_64 发行版（Debian 12/glibc 基线）。解压后运行
`./someip-agent`，无需另装 Python 或原生 SDK。默认仅监听本机回环地址。

- 底层采用固定版本 vsomeip 3.5.10，Python 保留控制层及 SAT 风格字典/socket 接口。
- 发行包内置 GitHub Releases 最新清单地址和正式 Ed25519 验签公钥；私钥不随包发布。
- 升级清单绑定版本、完整 ZIP 的 SHA-256 和固定版本下载地址；每次 HTTPS 跳转仍检查安全条件。
- 保留外置升级器、健康确认、启动失败回滚和安装状态查询。

## 已知限制

车型 ARXML 与 comm 的源冲突按用户要求保留：53 个事件组集合不一致、8 个事件在
当前 ARXML 投影缺失，6 个源服务未投影；103 条布局和177 条部署诊断仍需后续确认。
名称/ID 一致与虚拟网测试通过不等于所有实际车型服务已互操作验收。
Classic 未支持或未核验的布局继续保留运行门禁，不猜测序列化或擅自选择源优先级。

仅发布 Linux x86_64；Windows、Bootes、其他架构、跨发行版兼容及规模长稳不在本次验收范围。
真实网卡抓包、网络发送或提权仍需另行配置与授权，不会因安装而自动开启。

0.1.0 开发版没有内置正式更新信任根，首次升级须按打包文档配置公开清单地址和公钥，
或直接安装本版本；不要把测试密钥、测试清单或测试升级夹具作为正式源。
