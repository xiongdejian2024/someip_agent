# SOME/IP Agent 0.1.2

Linux x86_64 完整发行版（Debian 12/glibc 基线）。解压后运行 `./someip-agent`，
内置 Python、Node 22.19.0、Pi 运行时及原生 SDK 依赖，无需另装 Pi CLI、插件或 Skills。

- 智能体实际采用 Pi Agent Core / Pi AI 1.0.0 执行模型与工具循环，移除旧自研模型循环。
- 复用设置页网关、模型与凭据配置；同步/流式接口共用执行链路，取消会话会清理子进程。
- 暴露 `/api/v1/console/actions` 操作目录和受控执行 API，并提供有界页面导航命令。
- 控制台默认只读；写操作须每次显式授权，继续遵守 ARXML、原生能力与网络白名单门禁。
- 模型异常、截断、轮次超限不伪装成功；工具执行、拒绝与取消保留审计。
- 依赖版本和许可随包保存，不加载宿主插件、Skills 或任意 shell/文件操作工具。
- 未配置模型密钥时保持明确标记的本地只读证据模式，不伪装模型推理。

保留 0.1.1 的正式 Ed25519 验签信任根和 GitHub Releases 更新地址。
0.1.1 用户可通过设置页检查并安装本次签名升级；私钥不随包发布。

## 已知限制

车型 ARXML 与 comm 源冲突按用户要求保留：53 个事件组集合不一致、8 个事件在
当前 ARXML 投影缺失，6 个源服务未投影；103 条布局和 177 条部署诊断仍待确认。
名称/ID 一致与虚拟网测试不等于所有车型服务已互操作验收。
Classic 未支持或未核验的布局继续保留门禁，不猜测序列化或选择源优先级。

仅发布 Linux x86_64；Windows、Bootes、其他架构、跨发行版兼容及规模长稳不在范围内。
真实网卡抓包、网络发送或提权仍需配置与授权，不会因安装自动开启。
控制台授权参数不是远程身份认证，默认只监听本机回环，不能直接暴露公网。
本地模型夹具证明 SDK 集成，不证明所有企业模型网关兼容；实际网关须支持 SSE 与工具调用。
