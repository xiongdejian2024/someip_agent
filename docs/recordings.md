# 连续记录与离线回放

在监控页展开“连续记录与离线回放”，设置名称和额度后开始记录。记录只订阅应用的
`monitor_publish` 流，既不启动监听器，也不初始化或发送服务。它不是原始全网卡 PCAP：
原始 SOME/IP Payload、头字段投影、源时间与原生观测元数据会保存；没有看到的数据不会补造。
停止后排空已收到的队列并封存。网页冻结显示不会暂停录制；切换页面不会停止后台录制。

记录由独立磁盘分段承载，不依赖后端历史 deque 或网页 Trace 缓存。默认分段 8 MiB、
每次额度 256 MiB、队列 512 条；最多 4 路、128 次记录，整个记录目录额度 2 GiB。
额度耗尽停止并标记 `quota`，不覆盖旧分段；单条记录最大 8 MiB，不截断大报文冒充完整。
队列淘汰、过滤跳过、额度未录、异常中断未封存数量分别记录。配置参数只能选择额度/过滤，
不能传宿主路径。分段封存 flush/fsync 后生成 SHA-256；回放与导出均重新校验。
异常退出只认可清单中已封存的分段，状态为 `interrupted`，不声称完整；未封存帧另列。

停止后载入离线回放。时间轴使用监控到达的 monotonic 时间，Trace 保留原始报文时间；
波形随回放游标出现。支持暂停、单步一帧、0.1–10× 倍率、按 Service/Method/方向过滤及跳转。
过滤输入后点击“应用过滤/跳转”；读取失败暂停，不自动高频重试。离线帧不注入实时监控，
没有将记录发送到网络的 API。每页最多 1,000 帧、每次渲染释放最多 256 帧，展示继续使用有界缓存。

ZIP 导出包含清单和全部校验通过的 JSONL 分段，可归档和独立分析；分段也可单独下载。
当前回放加载保存在本机应用数据目录的记录，不把 ZIP 当可执行工程或网络发送配置。
导出并发最多两份，下载完成清理临时文件；取消请求等待生成完成后清理，避免释放额度后失控生成。
存储达到上限时应先导出，再按本机运维要求归档记录目录；本轮没有自动删除用户记录的策略。

API 位于 `/api/v1/recordings`：启动、状态、停止、分段下载、ZIP 导出与分页只读 frames。
所有 ID 是 UUID，分段名称由程序生成，拒绝符号链接和校验不一致。操作保留审计和异常堆栈。
