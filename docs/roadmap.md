路线图采用能力门禁而不是只按日期承诺。每个阶段必须有测试证据、支持矩阵和已知限制，未通过
门禁的能力继续标记为实验性。

## M0：可运行 MVP（0.1.x）

目标：完成端到端骨架，能够从 ARXML/PCAP 进入统一模型并在 Web 控制台观察。

- [x] 前后端分离骨架、REST/WebSocket 契约；
- [x] ARXML 安全解析和 SOME/IP 服务投影；
- [x] SOME/IP 基础报文、流边界与 SOME/IP-SD 基础结构；
- [x] PCAP/PCAPNG 离线导入；
- [x] 监控表格与基础波形；
- [x] OpenAI 兼容网关、模型白名单与密钥安全边界；
- [x] 语义版本校验、Docker 开发环境、Windows 构建骨架；
- [ ] 以真实去敏 ARXML/PCAP 建立回归样本和支持矩阵；
- [ ] 统一 API 错误码、请求 ID 和审计事件。

退出标准：单元测试覆盖关键编解码边界；恶意 XML/损坏 PCAP 不导致进程崩溃；全新环境可按
README 启动；Linux 独立发行包启动、签名升级和失败回滚验收通过。Windows 冒烟测试暂缓。

## M1：工程化信号仿真（0.2.x）

目标：可配置地模拟 provider/consumer，并把 payload 映射到车辆信号。

- 完整的服务实例、端点、eventgroup、method/event/field 部署映射；
- 标量、枚举、字符串、数组、结构体、union、字节序、对齐和长度字段；
- Find/Offer/StopOffer/Subscribe/SubscribeAck 的 TTL 与重试状态机；
- UDP/TCP 会话、多消息、TCP 重组和 SOME/IP-TP；
- 常量、阶跃、斜坡、正弦、随机、CSV、表达式和状态机信号源；
- 多 ECU 场景、确定性调度、暂停/单步/时间倍率；
- 波形游标、缩放、标记、降采样、CSV/PNG 导出；
- PCAP 时间轴联动与受控回放。

退出标准：与至少两个独立 SOME/IP 实现互操作；调度抖动和丢包有基准；未知 ARXML 类型拒绝
发送而不是猜测编码。

## M2：企业测试与安全发布（0.3.x）

目标：把交互式工具升级为可审计、可自动化的团队产品。

- 声明式场景、前置条件、动作、等待、断言、清理和参数化；
- 协议异常/边界测试模板、JUnit/HTML 报告、证据报文；
- CLI 无界面运行、并发 worker、CI/CT 集成；
- OIDC/LDAP、RBAC、工程级权限、操作审批与审计导出；
- Windows 代码签名、安装器签名、SBOM、第三方通知和漏洞门禁；
- Ed25519 签名更新清单、分渠道发布、断点下载、防降级与自动回滚；
- 工程 schema 迁移、备份/恢复和组织策略；
- 原生 vsomeip 适配器 PoC 与故障隔离。

退出标准：升级断电/损坏/签名失败演练通过；密钥不落前端和日志；发布制品可追溯到提交与
SBOM；权限绕过测试通过。

## M3：车载以太网深度能力（0.4–0.6）

- E2E profile、SOME/IP-TP、IPv6、VLAN、组播与 QoS 分析；
- 延迟、丢包、重复、乱序、损坏、错误返回码与 SD 风暴注入；
- DoIP/UDS、diagnostics-over-SOME/IP、XCP/CCP 连接器；
- Npcap/AF_PACKET、高性能 ring buffer、硬件时间戳与 PTP 指标；
- HIL I/O、通用仪器和厂商网络接口插件；
- 基于规范/项目数据的测试生成、异常聚类与根因候选；
- 需求映射、基线比较、覆盖率与结果趋势。

退出标准：插件故障不影响控制面；所有“通过/失败”结论可定位到确定性断言与原始证据；AI
输出不作为唯一判据。

## M4：规模化与生态（1.0 候选）

- 分布式采集/仿真代理、集中控制与资源调度；
- Linux/Windows x86_64 与 arm64 支持矩阵；
- 工程协作、制品库、远程台架预约和组织策略；
- 稳定插件 SDK、版本兼容策略与第三方插件签名；
- 长稳、压力、故障恢复、网络安全与升级演练常态化；
- 根据目标行业流程完成工具鉴定/合规资料包（如确有业务需求）。

1.0 门禁：API/工程格式有兼容承诺；安全响应与 LTS 策略明确；性能指标有可复现实验；发布、
回滚、备份和灾难恢复通过演练。

## 横向质量指标

| 维度 | 必须持续度量的指标 |
|---|---|
| 正确性 | golden packet 通过率、跨实现互操作、不支持 ARXML 元素数 |
| 性能 | RX/TX 吞吐、丢包、调度抖动、解析耗时、波形端到端延迟 |
| 稳定性 | 8/24/72 小时长稳、峰值内存、断网重连、插件恢复时间 |
| 安全 | 高危漏洞、越权、密钥泄露、恶意文件、升级签名失败用例 |
| 可观测性 | 请求/会话/报文关联率，错误堆栈完整率，审计覆盖率 |
| 可复现 | 工具/工程/场景/随机种子/输入哈希完整率 |
